# 🛡️ NetGuardIQ – AI-Assisted Network Threat Detection & Analyst Education Platform
## Overview
NetGuardIQ is a Python-based network security monitoring platform designed to help security analysts identify, investigate, and understand suspicious network activity in real time.
The project combines network discovery, ARP spoofing detection, URL reputation analysis, event management, and analyst-focused explanations into a single dashboard. Instead of only generating alerts, NetGuardIQ aims to explain why an event is suspicious and help analysts make informed decisions.
